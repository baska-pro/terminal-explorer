# Terminal Explorer v3.0.0

First stable universal release of Terminal Explorer.

Terminal Explorer is an interactive Bash + fzf file manager for Termux and Linux.

## Highlights

- Universal Termux and Linux support
- Interactive file and folder navigation with fzf
- File and folder previews
- Copy, cut, paste, move, rename and delete
- Bookmarks
- Search by filename and file content
- Archive compression and extraction
- chmod management
- Git repository information
- Safe protected-path handling
- Clipboard support
- Automatic package-manager detection
- Automatic bat / batcat detection
- `--doctor`, `--help`, and `--version`

## Supported environments

- Termux / Android
- Debian / Ubuntu
- Fedora / RHEL
- Arch Linux / Manjaro
- openSUSE
- Alpine Linux
- Void Linux
- Generic Linux environments with required dependencies

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/baska-pro/terminal-explorer/main/install.sh | bash
```

Run:

```bash
terminal-explorer
```

Alias:

```bash
texplorer
```
