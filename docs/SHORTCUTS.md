# Shortcuts

## Main list

| Key | Action |
|---|---|
| Enter | Open folder / file action |
| Alt+Enter | Folder action menu |
| Ctrl+H | Toggle hidden files |
| Ctrl+S | Sort/display menu |
| Ctrl+B | Bookmarks |
| Ctrl+F | Search by name |
| Ctrl+G | Search file contents |
| Ctrl+A | Bookmark current folder |
| Esc | Exit / cancel fzf |

## File menu

```text
e  edit
v  preview
r  run
i  info
p  chmod
y  internal copy
u  internal cut
c  copy to folder
m  move to folder
n  rename
d  delete
x  copy file content to system clipboard
h  truncate file
z  compress
k  extract when supported
b  back
```

## Folder menu

```text
e  enter folder
i  info
p  chmod
y  internal copy
u  internal cut
v  paste into folder
c  copy to folder
m  move to folder
n  rename
d  delete
z  compress
+  add bookmark
-  remove bookmark
b  back
```
